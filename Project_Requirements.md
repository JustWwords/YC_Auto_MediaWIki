# Требования к проекту

## Цель проекта

Развернуть корпоративный сервис ведения документации на базе MediaWiki, обеспечив:

* доступность веб-интерфейса;
* отказоустойчивость приложения и базы данных;
* резервное копирование контента и БД;
* мониторинг состояния сервиса.

## Требования к версиям

* Операционная система: Ubuntu 22.04 LTS.
* Балансировщик: Nginx 1.24.0.
* Веб-приложение: MediaWiki 1.46.0.
* База данных: PostgreSQL 16.

Для управляющей машины:

* Ansible 2.16.
* Terraform 1.9.2.

## Архитектура

* Фронтенд: один Nginx в роли балансировщика нагрузки.
* Бекенд: несколько экземпляров MediaWiki.
* Хранение данных: основная PostgreSQL и реплика на каждой машине с MediaWiki.

## Резервное копирование и скрипты

* Скрипт резервного копирования файлов MediaWiki.
* Скрипт резервного копирования базы PostgreSQL.
* Архивы должны сохраняться с меткой даты и иметь срок хранения.
* Скрипты должны принимать аргументы командной строки.
* Повторяющиеся действия в скриптах должны быть оформлены функциями.
* Ошибки должны обрабатываться.

## Мониторинг

* Установить Zabbix.
* Настроить мониторинг доступности HTTP-сервисов MediaWiki.

## Восстановлению инфраструктуры

* Описать план переключения на реплику PostgreSQL при отказе основной БД.
* Описать план восстановления инфраструктуры.
